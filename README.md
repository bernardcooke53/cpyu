# cpyu

[![PyPI - Version](https://img.shields.io/pypi/v/misprint.svg)](https://pypi.org/project/misprint)
[![PyPI - Python Version](https://img.shields.io/pypi/pyversions/misprint.svg)](https://pypi.org/project/misprint)

Zero-dependency, pure Python package to get CPU information.

Inspired by/derived from [`py-cpuinfo`](https://github.com/workhorsy/py-cpuinfo).
Fully type-annotated for use with [mypy](https://mypy.readthedocs.io/en/stable/).
